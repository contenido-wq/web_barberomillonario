## Descripción general
Landing page para un desarrollador inmobiliario de lujo, orientada a atraer compradores mostrando "una vida de ensueño junto al mar".

## Identidad visual
- **Tema:** Dark mode (interfaz oscura limpia)
- **Tono:** Lujo y sofisticación
- **Estilo:** Minimalismo contemporáneo — "nada distrae de elegir un hogar futuro"
- **Tipografía:** Prominente, con sistema tipográfico propio documentado en el proyecto
- **Fotografía:** Énfasis máximo en fotografías de arquitectura premium

## Pilares de diseño
1. **Minimalismo:** interfaz oscura limpia, sin distracciones
2. **Estética:** tipografía prominente + fotografía arquitectónica de alto nivel
3. **Funcionalidad:** estructura simplificada, catálogo de propiedades, versión móvil completa

## Secciones/componentes documentados
- Landing principal con hero visual
- Investigación y desarrollo (research)
- Análisis de audiencia objetivo
- Sistema tipográfico y de fuentes
- Paleta de colores personalizada
- Mapa interactivo de proyectos premium
- Testimonios de clientes y programa de fidelización
- Versiones desktop y mobile
- Sistema de cuadrícula (grid) adaptable
